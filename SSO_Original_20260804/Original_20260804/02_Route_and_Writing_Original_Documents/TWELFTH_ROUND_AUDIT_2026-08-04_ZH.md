## 五、我作为 SIMAX 审稿人的质疑，以及解答

**Q1. 「compact polar 会失效」不就是次微分集值这一众所周知的事实吗？**
答（应写进正文）：是的，集值性是经典的；本文的新对象不是次微分，而是**次微分与切性等式的交集**，以及在这个交集上的两件事——(i) 该交集何时是单点，(ii) 消失正则化沿哪条路径选到交集里的哪一点、以什么速率。第一件在 Thm 3.4 完全解决；第二件是第 4、5 节。开集性只是把「这不是零测度病态」这句话做实，应降格为命题或注记，不当卖点。

**Q2. `|a|<β` 与 `|a|=β` 这个二分有没有名字？**
答：有，而且现在稿件没有说出来。`∂φ(λ)=[a−β,a+β]` 意味着 `|a|<β ⟺ 0∈ri ∂φ(λ⋆)`，即标量问题有 weak sharp minimum；这正是这对原–对偶问题的**严格互补**在一维上的痕迹。核范数相对固定秩流形是 partly smooth 的，regular / strict / boundary 三个区制就是该分层的横截、非退化、退化三种情形。补上这段话，δ→δ^{2/3} 的指数跳变立刻与半定规划中心路径在退化最优点处失去解析性的经典现象对齐（Halická–de Klerk–Roos 两篇你 bib 里已有但**没有引用**，Basu–Mohammad-Nezhad 已引）。这段话成本半页，收益是把论文放进审稿人熟悉的坐标系。补丁见 P4。

**Q3. 为什么用 pseudo-Huber？换一个光滑化，结论还成立吗？δ^{2/3} 会不会是正则化子的人造产物？**
答：这是最尖锐的一问，而正确答案对论文**有利**，必须自己先说。见第六节 P2：换成 Huber，极限中心恰好是 K_F，边界律恰好是 Θ(δ)。也就是说——

- 第 3 节的**硬水填充完成 K_F 本身就是一个 Fenchel 中心**，只是对应另一个正则化子 `R=½‖·‖_F²+ι`；

```
Φ_δ − Φ_R⋆ = −(δ²/2) J⋆ + δ⁴[ (3/8)J₂ − (3χ₂/8d₀) U₀CV₀ᵀ ] + O(δ⁵).
```

推导只需把 `σ/√(σ²+ε²)` 展到四阶：`1 − ε²/(2σ²) + 3ε⁴/(8σ⁴)`，于是 `H(ε,0)=a − χ⋆ε²/2 + 3χ₂ε⁴/8 + O(ε⁶)`。成本：正文 6 行 + 补充材料一行表。

验证实例与数值见 P1 注释块；`(λ−λ⋆)/δ⁵` 在 δ=1e-2/1e-3/1e-4 上分别为 −0.1248207/−0.1249833/−0.1249999835，预测 −0.125。

### P2｜光滑化族与「两个中心」的统一（**最推荐**）

对 `ψ` 偶、凸、C¹、`ψ'` 严格增、`ψ(x)=|x|−c_ψ+o(1)`，取 `Ψ_δ^ψ(A)=δΣψ(σ_i/δ)`。则

1. Thm 4.3 逐字成立（只要 `ψ*` 强凸），极限中心是 `argmin_{P⋆} R_ψ`；
2. Thm 5.2 的证明**逐字成立**（它只用到精确尺度性 `Z_δ^ψ(B)=Z₁^ψ(B/δ)`、分离簇上的 `δψ(σ/δ)=σ−c_ψδ+o(δ)`、以及 ψ 的局部 Lipschitz），极限函数是 `F_ψ(t)=at+Σψ(tσ_i)`，中心核块是 `K_ψ=P_C diag(ψ'(t₀σ_i))Q_Cᵀ`；
3. `ψ_ph=√(1+x²)−1` ⇒ `K_ψ=K_R`，`t₀=−sign(a)η_R`；
4. `ψ_hub`（Huber）⇒ `R_ψ=½‖·‖_F²+ι`，`ψ'=clip`，于是 `K_ψ=K_F`、`t₀=−sign(a)η_F`——**水填充方程 `g_F(|t|)=|a|` 正是它的驻点条件**；
5. 边界指数由尾部决定：`ψ'(x)=1−γ_ψx^{−2}+O(x^{−4})` ⇒ `λ_δ−λ⋆ = −sign(a)(γ_ψ/(βκ))^{1/3}δ^{2/3}(1+o(1))`（pseudo-Huber 的 γ=1/2，回到 (2βκ)^{−1/3}）；而 `ψ'≡1` 于 [1,∞)（Huber）⇒ `λ⋆−λ_δ = δ/β + O(δ²)`。

数值确认（我独立跑的）：

| 实例 | pseudo-Huber | Huber |
|---|---|---|
| 对角余秩二（η_F=3/5, η_R=0.7150800690） | 斜率 →−η_R，方向 →Φ_R（δ=1e-5 时 7.7e-11） | 斜率 →−η_F（误差 5e-12），方向 →Φ_F（误差 6e-12） |
| 2×2 边界 b₁=b₂=c=1（β=κ=1/2） | x/δ^{2/3} → 1.2599209（=2^{1/3}） | x/δ → 1.9999999…（=1/β=2） |

为什么这条最值钱：
- 它把「为什么是 pseudo-Huber」从软肋变成结果；
- 它让第 3 节（硬完成）和第 4 节（软中心）之间有了因果结构，Cor 4.5 从孤立变成自然；
- 它是**纯矩阵分析**的陈述，正对 SIMAX 口味；
- 它几乎不花页数（一个命题 + 一个推论 + 一个 remark ≈ 1 页），却直接支撑「significant advance」。
