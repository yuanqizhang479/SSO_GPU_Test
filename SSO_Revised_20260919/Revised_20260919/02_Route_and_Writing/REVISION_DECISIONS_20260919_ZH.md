# 修改建议重新裁定与研究边界

日期：2026-09-19。比较基准为2026-08-04第十二版；本文件不把历史审计的“通过”当成当前证明。

## 1. 总体判断

继续推进一般矩阵线上的核范数最佳逼近、约束证书几何和奇异平滑路径。Xie等人的SSO是实际应用动机，不能作为未经修正的精确oracle定理前提；本研究的正确性和价值也不以指控原实验为假为依据。当前没有充分证据认定Xie存在实验伪造。

主研究不要求先复现Dense 1.7B、MoE和200层模型的全部训练。若新增“修复提升训练”“实际故障频繁”“相同算力下更优”等结论，才必须提交相应GPU证据。合成矩阵数值、CPU小模型流程验收、真实GPU训练是三种证据，不能互相冒充。

本次恢复了8月4日主稿、补充、源码、当时修订报告/审计/投稿信，8月15日与9月10日审计，9月14日复核裁决及9月15日整合建议。历史上下文提到的9月13日修订未找到可核实的独立稿件/源码包，因此没有把该记录中声称的证明、69条结果或GPU代码当成既成成果；本次以可恢复文件重新落实和检验。

## 2. 数学、写作和复现建议的裁定

| 建议 | 裁定 | 处理原则与理由 |
|---|---|---|
| 引言逐点核范数等同最小距离 | 必改 | 距离等于最小值，不等于任意乘子处的函数值 |
| relative-interior二分 | 必改 | 加上beta>0；beta=0时单点次微分的相对内部仍是自身 |
| 小奇异簇改用精确解析标架 | 采纳并完善 | 使用谱投影与精确块约化；仅有O(s)子空间扰动不足以直接给精确奇异值识别 |
| 任意余秩严格展开 | 保留，检查证明 | 不把方阵边界假设错误搬到所有严格点；重复正奇异值和矩形零空间需要正确分组 |
| 边界2/3律无条件推广 | 不采纳 | 保留方阵、余秩一、横截及正曲率等条件；高余秩/非横截不是已解决范围 |
| crossover只写“由解析性显然” | 必须展开 | 给出局部一致常数、各项余项和归一化估计；逐路径数值不能证明统一量词 |
| 增加更多主定理 | 原则上不采纳 | 优先闭合已承诺结论；可加入短的直接推论，不扩大成新的研究主轴 |
| 把一般核范数对偶/KKT列为首创 | 不采纳 | 明确经典基础，贡献落到具体切片、分类、中心和局部常数 |
| 强调不同中心作为SSO主要收益 | 不采纳 | SSO秩一法向的核压缩秩至多一，相应中心重合；不同中心体现一般法向情形 |
| 开失败集意味着训练故障普遍 | 不采纳 | 方阵开放性不提供真实轨迹频率；矩形嵌入反例不提供矩形全空间开放性 |
| 有限NS自动选择Fenchel中心 | 不采纳 | 需要另证相应谱映射/正则化与极限关系；固定步数多项式不是现有定理自动覆盖的路径 |
| Fenchel正则化球外仍写平方根 | 必改 | 先定义扩展值函数，避免在球外计算无定义实数平方根 |
| retraction和归一化省略非零/一致下界 | 采纳 | 明确映射定义域和随平滑参数的一致条件 |
| 最小Frobenius补全“无截断”端点措辞 | 采纳 | 约束可活跃但不需要改变未截断公式，两者应区分 |
| 推广可行性修复到一般法向 | 采纳为补充小结论 | 直接投影加缩放即可；不是新的主要创新 |
| 单报标量根残差 | 不充分 | 同一实际输出还要记录谱范数、真实/估计法向残差、可行修复后的gap |
| 用方向误差和目标损失比数量级 | 不采纳 | 不同指标无直接可比性；须在同一输入和输出下比较 |
| float64打印多位即高精度复现 | 不采纳 | 高精度脚本生成表格和JSON；保留原始输出与有限尺度参数 |
| python -O下仍宣布assert套件全通过 | 必改 | 拒绝优化模式或显式科学检查，不让判据静默消失 |
| 10个脚本通过证明所有定理 | 不采纳 | 数值回归与一般证明、原创性审查分别判断 |
| 浮点gap称机器严格证书 | 不采纳 | 精确实数定理可以给上界；普通浮点需要误差包络才能成为机器严格认证 |
| 补齐p=3、振荡路径、非对角50位表 | 采纳 | 让稿件所承诺的结果真正随包可生成 |
| 所有相关新文献一律加入 | 有选择采纳 | 优先最接近问题/可行集/平滑机制的文献，逐一写清差别，避免堆砌 |
| 补Skewon和更新MCSD | 采纳 | 特殊Stiefel闭式解已存在；投影球和交集球不是同一问题 |
| SIAM模板为绝对强制，超过20页不能投 | 修正措辞 | 依据现行官方说明报告真实页数和超长风险，不以压缩字体伪装合规 |
| 现在就给无条件Go/录用保证 | 不采纳 | 代码/格式/局部证明的检查不等于同行评审、全局查新或录用 |

## 3. 原SSO复核中不应写进数学稿的结论

| 争议 | 当前可支持的结论 | 不支持的外推 |
|---|---|---|
| Theorem A.3的单值零点保证 | 有明确反例，需完整次微分补全 | 所有有限NS实现训练失败 |
| 式(32) | 原式有绝对值，先前误读应撤回 | 继续称原文排版/推导错误 |
| 式(29)矩阵极限 | 原矩阵极限有问题，标量极限可另证 | 原定位界也因此一定错误 |
| 默认有根搜索静默回退 | 固定公开版本存在可运行反例 | 真实训练故障率已知 |
| 论文/代码混合精度不一致 | 需要实验commit与环境对应 | 已证明作者所用版本就是当前代码 |
| 公开评测校准请求混算 | 所检查代码数据组合有缺陷 | Table3已确定被该缺陷污染 |
| 样本数与百分比相容性 | 能条件性排除若干候选评测规模 | 已识别实际评测链，或另一条链必正确 |
| 等时间比较 | 公开曲线和单步时间可作条件折算 | 代替独立实测端到端GPU小时 |
| Table3优势较小 | 缺少逐题配对与多seed证据 | 统计上已证明效果为零 |
| CSQA净差贡献大 | 可做预先规定的敏感性分析 | 看到结果后删除任务 |
| µP迁移网格 | 有描述性支持但证据有限 | 完全无证据，或稳定性已获普遍证明 |
| 谱约束与weight decay | 约束范围/更新顺序应明确，已有消融也应承认 | 每个非顶奇异值能额外增长sqrt(d)倍 |
| 实验伪造 | 目前未证实 | 由数学错误、公开代码缺陷直接推定捏造 |

这些争议留在独立审计档案。修订数学稿只吸收集合值最优性、数值度量及实现边界，不把评测或诚信争议当成论文贡献。
